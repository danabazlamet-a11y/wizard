# Wizard Duel 🧙‍♂️⚔️

A simple browser-based wizard duel game built with JavaScript.

## 📌 Description

Wizard Duel is a small object-oriented JavaScript project that simulates a duel between two wizards.

Each wizard casts spells, consumes mana, and takes damage until one wizard wins the duel.

The project focuses on clean class design, encapsulation using private fields, and extendable game logic.

## 🚀 Features

- 🧙 Base Wizard class with private health and mana
- 🔥 FireWizard with ignite chance (bonus damage)
- ❄️ IceWizard with chill effect (mana drain)
- 🎲 Random turn order each round
- 🏆 Automatic winner detection
- 🔒 Encapsulation using private class fields
- 🧩 Easy to extend with new wizard types

## 🛠️ Technologies

- JavaScript (ES6+)
- HTML
- Browser Console

## ▶️ How to Run

1. Open `wizard.html` in your browser  
2. Enter names for the wizards when prompted  
3. Open the browser console to watch the duel
